🔒 Política de privacidade

Última atualização: outubro de 2026

1. Dados usados pelas ferramentas

O código desta versão realiza os cálculos, sorteios, quizzes e geração de senhas no navegador. O nick, a biblioteca de jogos, o XP e as preferências podem ser armazenados no armazenamento local do navegador (localStorage) para continuar disponíveis nesse mesmo navegador.

2. Dados pessoais

Esta versão não possui formulário de cadastro, conta de usuário ou servidor próprio para receber as informações inseridas nas ferramentas. Isso não significa que o provedor de hospedagem ou os serviços externos utilizados no futuro não possam tratar dados técnicos.

Os dados locais podem ser apagados pelo botão de redefinição abaixo ou pelas configurações do navegador. Apagar os dados locais pode remover o perfil, o progresso e a biblioteca.

A política deverá ser atualizada com os detalhes reais da integração.

Antes de publicar anúncios, configure os avisos e mecanismos de consentimento exigidos para os visitantes e regiões aplicáveis. Um simples botão de aceite não substitui automaticamente todas as obrigações legais ou as ferramentas de consentimento exigidas pelo fornecedor.
